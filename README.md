# પાંચાણી પરિવાર • શુભ લગ્ન નિમંત્રણ

Royal Gujarati Wedding Invitation Website for **Dharmik & Nisha**.

🔗 **Live Link:** [https://dharmikpanchani.github.io/panchaniweds/](https://dharmikpanchani.github.io/panchaniweds/)

## ✦ Key Features
- 🌸 **Royal Palace Theme:** Animated flower shower (ગુલાબ અને ગલગોટાની પુષ્પવૃષ્ટિ) & gold confetti.
- 🪔 **Traditional Gujarati Typography:** શ્રી ગણેશાય નમઃ, શુભ મુહૂર્ત, લગ્ન વિધિ અને સ્નેહ સંદેશ.
- 🪙 **Interactive Auto-Scratch Muhurat:** Automatic coin sweep with golden dust particles revealing the wedding date.
- 🐘 **Elephant & Gudiya Animations:** Traditional Gujarati animation welcoming guests.
- 📱 **Mobile First & Responsive:** Optimized for all screen sizes from mobile to desktop.
- 📲 **PWA Support:** Installable as an app with offline capability.
